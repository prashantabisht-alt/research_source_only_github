# ABP in 2D

This folder is the cleanest active Brownian particle branch in the source-only repo.

## Best Entry Points

| File | Role |
| --- | --- |
| `abp_fig1a_prash.f90` | MSD anisotropy with exact theory overlay |
| `abp_fig1b_snapshot.f90` | 2D snapshot / histogram pipeline |
| `abp_fig2a_samples.f90` | distribution slices in x and y |
| `abp_fig2b_radial.f90` | radial distribution branch |

## How To Run

```bash
bash run.sh --help
bash run.sh fig1a
bash run.sh fig2b
```
